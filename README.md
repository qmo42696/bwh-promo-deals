## 流量规则里两个最容易踩的坑

搬瓦工的流量标注看起来不小，实际用起来有两个规则要先知道，否则很容易觉得“流量凭空消失了”。

第一个坑：**双向计费**。上传和下载都消耗月流量，不分方向。普通建站用户基本无感（访客访问网站主要是出站流量），但如果拿来跑代理，一进一出都扣，实际可用流量大约是标称值的一半。1TB 的套餐当 500GB 用，是比较现实的预估。

流量用完了的处理方式也算透明：VPS 自动暂停、网络中断，不额外收费，等账单日（按你开通的日期算，不是每月 1 号）自动恢复；业务不能停的话，在后台的升级入口补差价换更高配的套餐，立即恢复上线。用到 80% 时官方会发邮件提醒。

搬瓦工支持退款，但条件比大多数人以为的严格，其中最容易误解的一条：**30 天期限从账户注册那天算起，不是从购买 VPS 那天算起**。老账户买新机器，是没有 30 天无理由退款这回事的。

- 账户创建不超过 30 天，账户信誉良好、无欠款、未违反服务条款
